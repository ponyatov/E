# Delimiters

- Special characters that structure code
    - Parentheses: `()` for grouping and function calls
    - Braces: `{}` for code blocks and data literals
    - Brackets: `[]` for arrays and indexing
    - Commas: `,` for separating items
    - Semicolons: `;` as statement delimiters
    - Colons: `:` for type annotations
