# frequency
## can be automatically recalculated to [[E/period|period]]

- `hz` hertz (slow control)
- `khz` (signals)
- `mhz` (RF & clock configuration)
- `ghz` (high-speed clocks)

can used in:
- realtime control [[E/annotation|annotations]]
- hardware clocks & timers configuration
- RF applications (wireless, radio equipment)
