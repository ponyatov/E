# Operators

1. **No implicit type promotion** 
	- Unlike [[Cpp/C|C]], E requires explicit type conversion
2. **Checked arithmetic**
	- By default, arithmetic operations check for overflow
3. **Deterministic behavior**
	- All operations have well-defined behavior and timings for [[hard real-time]]
