# 1. Tokens

**Tokens**: Identifiers, keywords (`actor`, `flow`, `send!`), literals (`42`, `1s`).

[[Evento]] programs are built from the following tokens:

![[E/Identifier|Identifier]]
![[E/Literals|Literals]]
        
        
- **Operators**:
    
    - Arithmetic: `+`, `-`, `*`, `/`, `%`
        
    - Comparison: `==`, `!=`, `<`, `>`, `<=`, `>=`
        
    - Logical: `&&`, `||`, `!`
        
    - Bitwise: `&`, `|`, `^`, `<<`, `>>`
        
    - Pipe (UFCS): `|>`
        
- **Delimiters**: `()`, `{}`, `[]`, `,`, `:`, `;`, `.`
