# measurement units

## time [[E/period|period]]

## data size & bit speed

- UART
	- `baud`
- `B` Bytes `buffer:[u32;256]`
- `K` Kilobytes `SDRAM:[u8;192K]`
	- `kbit`
- `M` Megabytes `let XRAM = 8M`
	- `mbit`
- `G` Gigabytes
	- `gbit`

## metric

- `m` meters
	- `km` kilometers
	- `cm` cantimeters
	- `mm` millimeters
- `in` inch
	- `mil` 1/100 inch (PCB design)

## graphic

- `px` pixels
- `pt` points (font size)
