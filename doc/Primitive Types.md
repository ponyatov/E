# Primitive Types

> Integers, floats, booleans, characters, etc.

- [[E/byte|byte]] single byte
- [[E/int|int]] integer number
	- unsigned: `u8` `u16` `u32` `u64`
	- signed: `i8` `i16` `i32` `i64`
- [[E/float|float]] floating-point number
	- `f16` `f32` `f64`
- [[E/char|char]] single wide char
- [[E/bool|bool]] boolean
	- `true`
	- `false`
