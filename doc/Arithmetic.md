# Arithmetic

## Infix

|Operator|Description|Example|Result|
|---|---|---|---|
|`+`|Addition|`5 + 3`|`8`|
|`-`|Subtraction|`7 - 2`|`5`|
|`*`|Multiplication|`4 * 6`|`24`|
|`/`|Division|`10 / 3`|`3`*|
|`%`|Modulus/Remainder|`10 % 3`|`1`|

## Unary
### Prefix

|Operator|Description|Example|Result|
|---|---|---|---|
|`+`|Positive (no-op)|`+5`|`5`|
|`-`|Negation|`-5`|`-5`|

### Suffix

|Operator|Description|Example|Result|
|---|---|---|---|
|`++`|Inxrement|`A++`|`A+1`|
|`--`|Decrement|`A--`|`A-1`|
